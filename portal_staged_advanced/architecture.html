المعمارية المؤسسية الشاملة ومصفوفة المتطلبات

خارطة الطريق التقنية الشاملة لـ 34 منظومة ونظاماً فرعياً تغطي الهوية الرقمية، النواة الأكاديمية، القبول والتسجيل، إدارة التعلم، شؤون الطلاب، والتكاملات المؤسسية مع متطلبات البيانات للتشغيل النهائي.

تنويه هندسي وتنفيذي للجامعة:

النسخة المرفوعة حالياً عبر الرابط الحي تمثل النموذج الأولي الفعّال (Interactive MVP v1.0) والتي تحتوي بالفعل على 21 صفحة ونظاماً نشطاً (البوابة، برامج الكليات الـ 17، القبول الذكي، دليل الرسوم، 16 خدمة طلابية، والمظهر المؤسسي). الأنظمة المتبقية مدرجة أدناه كجزء من بنية النظام الكامل وجاهزة للربط فور تزويدنا بالبيانات والربط السحابي.

الهيكلية البرمجية المعمارية الكاملة (Lusail University OS Tree)

تفريعات الـ 34 موديولاً ونظاماً فرعياً ومكوناتها التشغيلية

مصفوفة تسليم البيانات والملفات المطلوبة من إدارات جامعة لوسيل

لتغذية النظام بالبيانات الرسمية النهائية والاعتماد التشغيلي الكامل، يرجى تزويدنا بالملفات والشيتات المبينة أدناه بحسب الإدارة المعنية:

1. عمادة القبول والتسجيل (Admissions & Registration)

الخطط الأكاديمية واللوائح ورسوم البرامج
تحميل نموذج شيت البرامج (CSV)
المادة / البيان المطلوب الصيغة المفضلة الحالة في النسخة الحالية ملاحظات تقنية
الخطط الدراسية الكاملة للـ 17 تخصصاً مع رموز المقررات وساعاتها Excel / CSV مدمج بالكامل تم بناء جدول كامل بـ 17 برنامجاً وجاهز للمراجعة والاعتماد
جدول الرسوم الدراسية المعتمد للساعة ونسب المنح PDF رسمي مدمج وحاسبة نشطة الحاسبة التفاعلية تعمل برسم 1,600 ر.ق للساعة والمنح 10%-50%
سلم الدرجات وحساب المعدل التراكمي (GPA Scale) PDF / Excel نموذج قياسي معد تم تجهيز سلم درجات معياري (A إلى F مع نقاط 4.0)

2. الكليات الأكاديمية الأربع (The 4 Colleges)

التجارة، القانون، تكنولوجيا المعلومات، والتربية والآداب
المادة / البيان المطلوب الصيغة المفضلة الحالة في النسخة الحالية ملاحظات تقنية
قائمة أعضاء هيئة التدريس (الاسم، الرتبة، القسم، البريد) Excel Sheet قيد الانتظار لإنشاء صفحات البروفايل الأكاديمي ودليل التواصل
كلمة عمداء الكليات المحدثة والسيرة الذاتية الرسمية Word / Text صيغ نموذجية مفعلة تم وضع نصوص تأسيسية فاخرة لكل عمادة قابلة للاستبدال

3. عمادة شؤون الطلاب (Student Affairs & E-Services)

نماذج الخدمات الإلكترونية الـ 16 والأنشطة والأندية
المادة / البيان المطلوب الصيغة المفضلة الحالة في النسخة الحالية ملاحظات تقنية
الترويسة الرسمية المعتمدة لشهادات القيد والإفادات (Letterhead) Vector / PDF توليد رقمي نشط النظام يولد شهادات رقمية بـ QR Code مطابق للهوية المؤسسية
قائمة الأندية الطلابية المعتمدة وضوابط التسجيل Word / PDF مدمج في الموقع صفحة الحياة الجامعية تضم 6 أندية نموذجية مع استمارات انضمام

4. إدارة تقنية المعلومات (IT & Infrastructure)

الربط بالنطاق الرسمي lu.edu.qa والهوية الموحدة Microsoft Entra
المادة / البيان المطلوب الصيغة المفضلة الحالة في النسخة الحالية ملاحظات تقنية
إعداد سجلات DNS (CNAME / A Records) للنطاق lu.edu.qa DNS Records جاهز للربط الفوري سيتم تزويد الـ IT بسجلات الـ CNAME فور رغبتهم بربط الدومين الرسمي
بيانات تطبيق Microsoft Entra ID (Client ID / Tenant ID) للدخول الموحد Azure App Reg مهيأ برمجياً كود الدخول الموحد SSO مكتمل ومجهز للربط بالـ Tenant الجامعي
